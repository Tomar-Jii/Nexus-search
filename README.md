## 🌟 Key Features & Systems

### 1. Dual AI Personas: Angel & Devil
- **Angel AI (Gold Accent)**:
  - Personality: Calm, intellectual, supportive, and constructive research companion.
  - Aesthetic: Radiant gold `#EAB308` interface accents.
- **Devil AI (Crimson Accent)**:
  - Personality: Bold, sharp, high-impact, and cyber-futuristic intelligence.
  - Aesthetic: Crimson `#EF4444` and onyx dark interface accents.
- **Security & Integrity**:
  - Persona modes: `Auto (Theme)`, `Angel AI (Gold)`, and `Devil AI (Crimson)`.
  - Built-in prompt-injection defense and creator identity defense for **Death Game Boy 375**.

### 2. Dual-Mode Search & Gemini 3.8 Flash Synthesis
- **Public & Live Search**: DuckDuckGo live instant topics, OpenSearch suggestions from Wikipedia, and resilient curated datasets.
- **Multi-Category Tabs**: `All`, `Images`, `Videos`, and `News`.
- **AI Overview Card**: Synthesizes verified answers with inline source citation badges (`[1]`, `[2]`), concise key takeaways, and direct grounding links.
- **Voice Search**: Real-time voice dictation with audio wave visualization and text fallback.

### 3. Deep Research Engine
- **Multi-Stage Query Decomposition**: Formulates sub-queries, executes parallel searches, cross-references credibility, and highlights contradictions and engineering trade-offs.
- **Configurable Depths**: `Quick` (1 query), `Deep` (4 dimensions), and `Extended` (6 dimensions).
- **Executive Reports**: Confidence scores, verified takeaways, cross-source contradictions, and one-tap Markdown report export/sharing.

### 4. Tor & Onion Private Network Layer
- **Fail-Closed Privacy Architecture**: All `.onion` requests and Tor tabs require an active circuit; clearnet fallback is strictly blocked.
- **Interactive 3-Hop Circuit Visualizer**: Live Guard -> Middle -> Exit relay indicators.
- **Pluggable Transports / Bridges**: Snowflake & obfs4 anti-censorship support.
- **NEWNYM Identity Renewal**: Rebuilds a fresh 3-hop circuit on demand.

### 5. Multi-Tab Native Browser
- Multi-tab management, incognito mode, and dedicated Tor onion session tabs.
- Distraction-free **Reader Mode** and **Desktop Site** toggles.
- Real-time tracker blocking telemetry and extension script sandbox.

### 6. WebExtensions Platform
- Store catalog and installed management for:
  - **uBlock Origin Lite**: Ad-blocking and tracking neutralization.
  - **Privacy Badger**: Third-party tracker isolation.
  - **HTTPS Everywhere**: Protocol encryption upgrade.
  - **Dark Reader**: High-contrast dark stylesheets.
  - **NoScript Lite**: Script execution control.
  - **ClearURLs**: Hyperlink parameter cleansing.
- Detailed permission review dialog before installation.

### 7. Security Center & Diagnostics
- Zero-Trust status ("SYSTEM FULLY HARDENED").
- Live security audit button and tracker telemetry counters.
- HTTPS-only enforcement, WebRTC IP Shield, and DNS leak protection.

### 8. Persistence & Privacy Governance
- Persistent local storage for search history, bookmarks (with folder tagging), installed extensions, and research reports.
- Incognito search toggle (never saves history).
- One-tap "Clear All Browsing Data" sanitization.
